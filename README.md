# 农资销售助理 Agent（原型）

让不懂农资的店员也能安全卖药：问症状 → 诊断 → 查对症且已登记的药 → 算用量 → 报价 → 开单并打印用药说明。

## 快速开始（最简单）

1. 到 https://platform.deepseek.com 注册、充值，创建 API Key
2. 在本文件夹新建 `api_key.txt`，把 Key 粘贴进去保存
3. 双击 `启动.bat`，浏览器会自动打开

手动方式：
```bash
pip install -r requirements.txt
set DEEPSEEK_API_KEY=你的key
python test_tools.py                   # 离线测试，不花钱
streamlit run app.py --server.address 0.0.0.0    # 网页版
python agent.py                        # 或者命令行版
```

### 网页版在平板/手机上用
1. 电脑上启动后，在命令行里运行 `ipconfig` 查看电脑的 IPv4 地址（如 192.168.1.5）
2. 平板连同一个 WiFi，浏览器打开 `http://192.168.1.5:8501`
3. 如果打不开，在 Windows 防火墙里放行 8501 端口

> **拍照诊断（可选）**：到阿里云百炼 https://bailian.console.aliyun.com 开通并创建 API Key，
> 存为本文件夹的 `qwen_key.txt`，重启即可。照片由通义千问视觉模型识别，再交给 DeepSeek 判断和匹配药。

示例对话：
```
店员：客户说他家土豆叶子上有黑褐色的斑，叶子背面有白毛，最近下了好几天雨，种了20亩
店员：他嫌贵，问烯酰吗啉13块一袋行不行
店员：行，他要了，叫张大爷，电话138xxxx
```

## 文件说明

| 文件 | 作用 |
|---|---|
| `data/products.csv` | 商品、售价、**底价**、库存 —— 店主用 Excel 维护 |
| `data/registrations.csv` | 每个药登记的作物、防治对象、亩用量、安全间隔期 —— **照抄农药标签** |
| `store.py` | CSV → SQLite，订单和转人工记录 |
| `tools.py` | Agent 能用的 7 个工具 |
| `agent.py` | 对话核心和命令行版（系统提示词在这里） |
| `app.py` | 网页版界面 |
| `orders/` | 自动生成的用药说明，可直接打印 |

改完 CSV 后运行 `python agent.py --reload` 重新导入。已有商品只更新资料和价格，**不会改动库存**。
更推荐直接用网页左侧的 **老板后台**（密码在 `settings.txt` 的 `ADMIN_PASSWORD`）：
- 📊 经营概况：销售额、毛利、畅销商品、库存预警
- 🚚 进货入库：加库存，同时自动生成采购台账
- 💰 商品与价格：改售价/底价、补登记证号、新增商品、编辑登记用途（会自动同步回 CSV）
- 📒 台账导出：按《农药管理条例》要求的字段导出销售台账、采购台账（Excel 可打开）
- 🧾 订单管理：查看订单、作废订单（库存自动加回）

## ⚠️ 上线前必须做

1. **示例数据不能直接用于真实销售**。`registrations.csv` 里的用量是示意数据，必须逐条对照实物标签，
   或者到中国农药信息网（www.icama.org.cn）按登记证号核对后替换。
2. 把店里真实的商品、价格、底价录入 `products.csv`。
3. 资质：店铺需要有农药经营许可证；限制使用农药要实名销售。建议老板保留远程审核。
4. 试运行期间让老板复核每一单，积累准确率数据。
